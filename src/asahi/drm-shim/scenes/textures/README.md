# Apple9 sampled textures

Mesa-generated vertex/fragment shaders use ordinary Gallium texture and sampler
bindings. Supported sampling is FP32 implicit-LOD 2D, with one texture/sampler
binding pair per fragment shader. Repeated samples, structured branches and
loops, nearest/linear minification and magnification, clamp-to-edge, mipmaps,
and nearest/linear mip filtering are implemented. API texture units are compacted
to the hardware binding independently for each draw.

Uncompressed R8, RG8, RGBA8, RGBX8, BGRA8 and BGRX8 UNORM views use the normal
format/swizzle path. BGRA8 backs GL_RGBA8 render targets in the compatibility
attachment path. Mesa's CPU transfer fallback converts uploads when needed;
resource hazards synchronize render-to-texture followed by sampling. Mipmap
generation currently runs on the CPU through synchronized Gallium maps.

After resetting and chainloading m1n1, run:

```sh
src/asahi/drm-shim/scenes/textures/run.sh /absolute/path/to/new-output
```

Each run produces two 256x256 attachments and checks all pixels against an
independent CPU oracle, including alpha. The default samples 64x64 RGBA patterns
and switches API units 3/1 between frames. Reset and chainload before each new
process. The following environment variables select further tests:

| Variables | Coverage |
| --- | --- |
| `T8132_GLES_TEXTURES_MIXED=1` | Three draws per batch: textured/untextured/textured, binding and tint changes, scissors and out-of-range UVs |
| `T8132_TEXTURE_LINEAR=1` | Bilinear filtering; combines with mixed draws, atlases and mipmaps |
| `T8132_TEXTURE_RTT=1` | Render to a canvas, then sample it into the final target without an intervening `glFinish` |
| `T8132_TEXTURE_BLEND=1` | Sample and alpha-blend over a drawn background; combines with RTT |
| `T8132_TEXTURE_REPEAT=1 T8132_TEXTURE_FRAGMENT_SOURCE=.../fragment-repeat.glsl` | Two distinct sampling coordinates |
| `T8132_TEXTURE_LOOPS=7 T8132_TEXTURE_FRAGMENT_SOURCE=.../fragment-fixed-loops.glsl` | 49 samples in nested constant-bound loops; guards against frontend unrolling/code-size growth |
| `T8132_TEXTURE_LOOPS=9 T8132_TEXTURE_FRAGMENT_SOURCE=.../fragment-loops.glsl` | 81 samples per pixel in nested runtime loops, spatial branches, Boolean uniform changes |
| `T8132_TEXTURE_MIPS=384` | Full NPOT mip pyramid with distinct colors, all implicit LODs, triangle/scissor edges |
| `T8132_TEXTURE_MIPS=994 T8132_TEXTURE_MIP_HEIGHT=950` | Rectangular mip pyramid; catches inherited large-level allocation padding omitted by a per-level area model |
| `T8132_TEXTURE_MIPS=1846 T8132_TEXTURE_MIP_HEIGHT=760 T8132_TEXTURE_MIP_LINEAR=1 T8132_TEXTURE_LINEAR=1` | Wide rectangular atlas with trilinear filtering across all levels |
| `T8132_TEXTURE_MIP_LINEAR=1` | Fractional LODs, alongside `T8132_TEXTURE_MIPS`; add `T8132_TEXTURE_LINEAR=1` for trilinear |
| `T8132_TEXTURE_GENERATE_MIPS=1` | `glGenerateMipmap` from a checkerboard, alongside `T8132_TEXTURE_MIPS` |
| `T8132_TEXTURE_ATLAS=2048 T8132_TEXTURE_ATLAS_HEIGHT=1024` | Large atlas and a 97x83 partial update with padded upload rows |
| `T8132_TEXTURE_ATLAS=513 T8132_TEXTURE_ATLAS_HEIGHT=257 T8132_TEXTURE_CHANNELS=1` | NPOT R8 atlas, white RGB/red alpha swizzle and partial update |
| Same atlas variables with `T8132_TEXTURE_CHANNELS=2` | RG8 atlas, luminance/alpha swizzle and partial update |
| Add `T8132_TEXTURE_LEGACY=1` to the two-channel atlas | Legacy `GL_LUMINANCE_ALPHA` upload and update |

Use absolute paths for fragment-source overrides. The attachment is read through
the shim's synchronized dump facility; `glReadPixels` is not covered.

The compatibility packager requires the complete external
`render_texture_coords8_launch.bin` (256 bytes, SHA-256
`380fe0f9a88408f1258947bf092e4ab4261217d6953005abb4ddac04af8fbc8e`).
The launcher stays opaque; both API shader mains are generated by Mesa.
Initial capture provenance is in `tmp/apple9-textures/`; the expanded feature
validation and discovered compiler bugs are in `tmp/apple9-texture-features/`.

Remaining limits include multiple texture/sampler pairs in one shader, explicit
LOD/gradient/texel-fetch instructions, nonzero base-level views, other wrap modes,
compressed/sRGB/integer formats, and non-2D or multisampled textures. This is a
bounded bring-up path, not a claim of complete GLES conformance.
